# Sparkle Suite 2.0

**A little bit of sparkle, everywhere.**

A collection of sparkle overlays and visual effects, made to bring a little extra magic to the platforms we use every day.

From your desktop to your browser, phone, and notes - there's a sparkle for that.

## Projects

| Project         | Description                                       |
| --------------- | ------------------------------------------------- |
| **[Android](https://github.com/sparkles-everywhere/sparkle-android)**  | A sparkle overlay for Android.                    |
| **[Desktop](https://github.com/sparkles-everywhere/sparkle-desktop)** | A Python-based desktop sparkle overlay.           |
| **[Cursor](https://github.com/sparkles-everywhere/sparkle-cursor)**  | Sparkles that follow your mouse.                  |
| **[Web](https://github.com/sparkles-everywhere/sparkle-userscript)**      | A userscript that brings sparkles to the browser. |
| **[ObsidianMD](https://github.com/sparkles-everywhere/sparkle-obsidian)** | A sparkle plugin for your notes.                  |

*Each project is maintained in its own repository.*

## The idea

I was using Discord, saw someone's profile effect, and went "Why don't I do that everywhere?"

So I did.

Each project aims to follow the same concept: lightweight, customisable sparkle effects.

Explore the repositories, pick your platform, and make your digital experience a little more magical.

Leave a star if you like any of the versions :)
